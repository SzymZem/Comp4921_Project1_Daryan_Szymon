Project Requirements (https://learn.bcit.ca/d2l/le/dropbox/1233774/694229/DownloadAttachment?fid=48893250):
✅ Authentication (login with hashed passwords, password validation >= 10 characters with upper/lower, numbers, symbols)
- Hosted on Render, Cyclic, etc
- Must be logged in to create content.
- Do not need to be logged in to view content.
- Authorization (you can only edit your creations, any attempt to edit anyone else's results in a 400)
- Sessions (Cookies in an encrypted MongoDB)
- Function to generate URL friendly PK (check to see if you have duplicates, and race conditions) – don't use autogenerated PKs
- Allow for custom URL's (if not taken)
- Allow for redirects to be deactivated and/or deleted.
- Show text or image or redirect
- Use a service like cloudinary to store images
- Show stats on number of hits
- Must have a pretty interface (think Bulma, Bootstrap, etc.)
    - Minimize custom CSS
    - Common header footer with highlighting links
    - Button to login / log out (depends on if you are logged in)
- Full text search for text field?
- Good database design, normalized (non-redundant), secure
- Professional looking 404 page
- Ability to enable and disable links. Disabled links will display a message such as content not available.
